# Assignment 1 — Parameter Estimation

## Overview

This repository contains the solution for **Assignment 1 — Parameter Estimation**.

The task is to recover the three unknown parameters `theta`, `M`, and `X` from 1,500 observed `(x, y)` points generated by a parametric curve.

The assignment specifies the following parameter ranges:

```text
0 < theta < 50 degrees
-0.05 < M < 0.05
0 < X < 100
6 < t < 60
```

The assessment focuses on:

1. L1 distance between uniformly sampled points on the expected and predicted curves.
2. Explanation of the complete process and steps followed.
3. Submitted code / GitHub repository.

Additional mathematical derivation and code used to estimate the unknown variables are included in this repository.

---

## Parametric Curve

The curve is:

```text
x = t*cos(theta)
    - exp(M*|t|)*sin(0.3*t)*sin(theta) + X

y = 42 + t*sin(theta)
    + exp(M*|t|)*sin(0.3*t)*cos(theta)
```

with:

```text
6 < t < 60
```

---

## Final Result

The recovered parameters are:

| Parameter | Estimated value | Clean value |
|-----------|-----------------|-------------|
| `theta` | 29.9999729322° | **30°** |
| `M` | 0.0299999969 | **0.03** |
| `X` | 54.9999982128 | **55** |

Therefore the final curve can be written as:

```text
x = t*cos(30°)
    - exp(0.03*t)*sin(0.3*t)*sin(30°) + 55

y = 42 + t*sin(30°)
    + exp(0.03*t)*sin(0.3*t)*cos(30°)

6 < t < 60
```

---

## Method

Instead of treating every point's `t` value as an independent optimization variable, the equations are projected onto directions parallel and perpendicular to the curve orientation.

### Parallel projection

The projection:

```text
(x - X)*cos(theta) + (y - 42)*sin(theta)
```

cancels the oscillating terms and gives:

```text
t = (x - X)*cos(theta) + (y - 42)*sin(theta)
```

This allows `t` to be recovered directly for each observed point.

### Perpendicular projection

The perpendicular projection:

```text
-(x - X)*sin(theta) + (y - 42)*cos(theta)
```

isolates the oscillating component:

```text
exp(M*t)*sin(0.3*t)
```

because the assignment requires `6 < t < 60`, so `t` is positive and `|t| = t`.

The resulting residual is minimized using bounded nonlinear least squares.

---

## Optimization

The implementation uses:

```text
scipy.optimize.least_squares
```

with the optimization vector:

```text
[theta, M, X]
```

Multiple initial parameter guesses are tested, and the best valid solution is selected.

A candidate solution is required to satisfy:

```text
0 < theta < 50 degrees
-0.05 < M < 0.05
0 < X < 100
6 < t < 60
```

## How to Run

From the project root:

```bash
python3 solve.py
```

The script will:

1. Load `xy_data.csv`.
2. Validate the input columns.
3. Estimate `theta`, `M`, and `X`.
4. Recover the corresponding `t` values.
5. Validate parameter and `t` constraints.
6. Reconstruct the curve.
7. Calculate residual and coordinate errors.
8. Perform the uniformly sampled curve comparison.
9. Save numerical results.
10. Generate the fitted curve plot.
